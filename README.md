# Student Record Management System

A console-based C++ application to manage student records.

## Features
- Add students (ID, name, marks)
- Display all records
- Search student by ID
- Delete student by ID
- Data saved to file — persists between sessions

## Concepts Used
- Object-Oriented Programming (classes, constructors)
- File I/O (fstream)
- Arrays
- Error handling (duplicate IDs, missing records)

## How to Run
1. Compile with any C++ compiler (g++, VS Code)
2. Run the executable
3. Use the menu to manage records
